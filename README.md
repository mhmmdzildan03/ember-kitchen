Ember Kitchen — Sizzle & Serve: a complete one-chef cooking game. Grab ingredients from the counter, grill patties before they burn, chop vegetables on the board, build each dish exactly as the order board asks, and ring the serve bell before the ticket runs out. Orders get faster and fancier as the shift goes on; three lost orders end your shift. Score, coins, combos, levels, a 150-second shift timer, synthesised sizzle/chop/ding sounds, and a best score that survives between visits.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click the bins, grill, board and plate — or use keys 1-6 to grab, Space to serve, T to trash, P to pause, M to mute. No network requests, no build step: the whole game is static files under game/.
